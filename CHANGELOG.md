# Changelog

## 0.1.0a1 — 2026-10-17 (candidato local)

### Added

- Tema Bootstrap para el admin nativo: login, navegación, listados, formularios,
  inlines, widgets de relaciones, historial, borrado y páginas de cuenta.
- Modos claro, oscuro y automático, con acabado de vidrio discreto.
- Dashboards extensibles en Python y Apache ECharts local, con datos tabulares.
- Marca, iconos, enlaces con permisos, CSS y configuración por AdminSite.
- Documentación Sphinx de instalación, configuración y extensiones.
- Matriz de pruebas Django 6.0/6.1 y Python 3.13/3.14; recursos incluidos en el wheel.

### Limitations

- Primera alfa: API y presentación sujetas a cambios; probar antes de producción.
- Las personalizaciones del consumidor y widgets de terceros requieren validación propia.
- Las comprobaciones automáticas de accesibilidad no equivalen a certificación WCAG.
